# RC structure-record parameter-space projection

TensorFlow Embedding Projector bundle for 3,800 parameterized reinforced-concrete structure/ground-motion samples.

- `vectors.tsv`: 3,800 standardized vectors with 55 dimensions.
- `metadata.tsv`: matching metadata in identical row order. The local `source_path` column is intentionally omitted from this public copy.
- `projector_config.json`: hosted configuration consumed by TensorFlow Embedding Projector.

Open the visualization:

https://projector.tensorflow.org/?config=https://raw.githubusercontent.com/Alejandro-AlfaroT/StructGNN-OpenSeesPy-Integrated/main/projector_share/structure_record_3800/projector_config.json
