1. Rectangular versus slab-inclusive beam bending stiffness.

with no load-transfer step between them. Support-motion feedback matters,
but adding an iteration around the existing floor routine does not by itself
make its model equivalent to the eccentric reference.

## 4. Findings in experimental order

### Beam stiffness

The frame originally uses rectangular Iy = 4860 in4. The floor routine uses
T/L properties: gross Iy = 7013.07 edge / 8320.03 interior in4; its beam
elements subtract flange mid-plane inertia already represented by shells,
giving net Iy = 6773.49 / 7945.03 in4.

Changing ONLY the temporary bare frame's vertical bending Iy to gross T/L
values reduced case 0144's original-reference vertical mismatch to
1.28139% / 1.21708% (full/pattern). The same probe reduced all five failed
cases to below 2% for both load cases, and two passing controls remained
below 1.2%. This was diagnostic, not requalification or a complete composite
stiffness prescription.

### Floor constraints

The bare frame has rigid diaphragms at column joints. The original eccentric
coupled reference has finite shell membrane stiffness and no diaphragm.
Matching rigid constraints ONLY at column intersections in that reference
brought corner moment-magnitude sums within 1%, and edge sums within about
4.2%, of the temporary T/L frame. These are group sums, not bounds on each
signed moment component.

Constraining EVERY shell node is not equivalent and worsened vertical
distribution. Do not use that as a repair.

Rigid links plus added diaphragm MPs form constraint chains. Diagnostic
solves used Lagrange constraints and UmfPack; a no-diaphragm Lagrange control
reproduced the original Transformation solution to roundoff. Do not apply
Transformation naively to chained retained/constrained nodes.

### Numerical suspects ruled down

- PDelta-to-Linear column transformation change: roundoff under full gravity;
  under patterned gravity <0.0018% vertical change and <0.021 kip-in base
  moment-component change. This does not diminish PDelta's general seismic
  importance.
- Interior-couple force-pair arm reduced from 1 in to 0.25 / 0.1 in:
  maximum base moment-component change <0.00007 kip-in.
- Transfer mesh 16 to 24: vertical changes <0.008%; base moment-component
  changes <0.176 kip-in. The affected interior moment sign persisted.
- Coupled mesh 8 to 9 still moved moments up to 0.347 kip-in in the matched-
  diaphragm tests. Do not claim a fully mesh-converged reference. Mesh 9
  uses 7776 shells; mesh 10 exceeds the current 8192-shell building cap.

### Support movement feedback

Each floor was reanalyzed with its frame's vertical displacements and
bending rotations, then its own transfer was applied to that story.

Prescribing rotations creates support reaction moments. The diagnostic
extractor subtracts these from beam-end couples when finding slab-on-frame
couples, and includes them in global equilibrium. The production extractor
was not changed; its freely rotating supports have zero such moments.

Replay controls (the floor's own movements, then a uniform 0.01-in vertical
translation) reproduced original transfer loads within 7e-11 in the relevant
kip/kip-in components. The custom story-load applier reproduced the previous
frame response within 7.1e-9. Every floor's corrected equilibrium passed.

After eight half-relaxed updates and one additional verification pass,
fixed-point residuals were <4.85e-7 in vertical movement and <1.40e-9 rad
rotation. This is convergence of the diagnostic mapping, not physical-model
validation.

Against the eccentric reference with matched column-joint diaphragms:

| Feedback result | Full | Pattern |
|---|---:|---:|
| Max vertical mismatch | 2.17851% | 2.12337% |
| Max base moment-component gap | 6.50222 kip-in | 6.12438 kip-in |

The full-gravity interior My at (5,1) moved from -4.59862 to -2.07236 kip-in,
but the eccentric comparator stayed +1.62502 kip-in. Thus feedback matters
but is not a sufficient standalone repair.

### Strongest new result: monolithic representation control

We changed the reference assembly in memory to place centroidal beams on
the slab plane with the floor routine's exact net T/L properties. The slab
pressure and actual member-weight ledgers stayed identical. All eight
representation-control solves passed equilibrium and rigid-link checks.

Comparing the feedback solution to this centroidal whole-building model:

| Difference | Full | Pattern |
|---|---:|---:|
| Maximum vertical reaction | 0.23375% | 0.23641% |
| Maximum base moment component | 0.61689 kip-in | 0.58741 kip-in |

At (5,1), full gravity:

| Model | Base My |
|---|---:|
| Feedback calculation | -2.07236 kip-in |
| Monolithic centroidal floor-section model | -1.98976 kip-in |
| Monolithic eccentric web reference | +1.62502 kip-in |

**The opposite sign exists between two monolithic models with no transfer
step. This strongly attributes the bulk of the remaining discrepancy to
beam/slab representation, not the routine applying exported couples.** It
does not prove either representation is sufficiently accurate for design.

A separate G=0.4E versus E/[2(1+0.2)] control changed verticals by at most
0.03381% and moment components by at most 0.11635 kip-in: not the main cause.
A full-T-plus-explicit-shell overlap sensitivity was also run; it is NOT a
recommended model even though some differences were smaller.

## 5. What remains open; recommended next work

Continue investigation/design-method review before implementing a production
repair. In order:

1. **Choose and justify the intended beam/slab physical idealization.**
   Decide how eccentricity, membrane interaction, effective flange width,
   and gross/cracked stiffness should be represented. Do not select a model
   merely because it passes the existing comparison.
2. **Close the residual partitioned-versus-monolithic differences on a
   genuinely matched representation.** Use the same net beam/shell stiffness
   bookkeeping, matching meshes and constraint assumptions. Current feedback
   uses a gross T/L receiving beam while the floor subtracts the shell's
   flange mid-plane term; it is not an exact partition.
3. **Check beam-weight feedback.** Floor reanalysis applies slab pressure
   only; physical beam weight remains in the receiving frame. Joint-motion
   feedback alone does not fully reproduce interior beam deformation and
   slab redistribution caused by that distributed member weight. Include
   this in a matched diagnostic without exporting/counting weight twice.
4. **Check signed member/joint actions, not only base totals.** Compare
   section-cut composite slab-plus-web actions with frame moments; a web
   segment moment alone is not composite beam demand. Resolve reference
   mesh sensitivity and relevant floor displacements/rotations.
5. **Only after selecting and verifying a repair:** add regression tests,
   revalidate all five failures and representative passing cases, and review
   consequences for periods/drift, capacity-design forces, slab reinforcement,
   effective stiffness and the IMK response model. Use fresh artifact roots
   after production design-method changes.

Keep the eccentric coupled reference as an independent diagnostic. Do not
replace it merely to obtain a pass, resize case 0144 blindly, alter saved
evidence, or flip Config.py assertions. The investigator has not established
that the original rejected designs are safe to accept.
